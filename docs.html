01快速上手

源文件用 UTF-8 保存，后缀 .gl。三种运行方式任选一种，跑的是同一份解释器内核。

第一个程序

# 注释用井号；也可以用「注」开头
设 名字 为 "世界"
输出 "你好，", 名字

重复 序号 从 1 到 3
    输出 "第 ", 序号, " 次"
结束

三种运行方式

方式怎么做
图形工作台
glang-workbench.exe		左边写代码 → F11 运行，右上输出、右下填输入。装好即用。
命令行
glang 程序.gl		在 cmd / PowerShell 里直接跑，适合管道与批处理。
网页演练场
playground.html		不装任何东西，浏览器里写、浏览器里跑（本站实现，覆盖常用语法）。

命令行参数

命令作用
glang 程序.gl运行程序
glang --检查 程序.gl只检查语法，不执行
glang --提示 程序.gl显示全角符号纠正、GBK 转码等提醒
glang --版本 / glang --帮助版本与用法

工作台快捷键

按键作用
F11 或 Ctrl+Enter运行程序
F9只检查语法，不执行
Esc停止正在运行的程序
Ctrl+O / Ctrl+S打开 / 保存 .gl 文件
Ctrl+Shift+S另存为
Tab缩进四个空格，不会跳走焦点
输入怎么办？程序里每个「输入」按顺序读「输入框」里的一行，留空就是 空。需要键盘输入的示例（两数求和、判断闰年、猜数字），先在输入区填好再按 F11。

02语法速查

变量：四种前缀决定它落在哪一层

写法落点典型用途
设 x 为 1当前函数（顶层即全局）日常赋值，最常用
局部 x 为 1当前块（如果 / 重复 / 当 / 遍历 体内）临时变量，不污染函数其余部分
全局 x 为 1全局函数里维护计数器、配置
非局部 x 为 1外层函数的同名变量闭包里累加状态
常量 π 为 3.1416全局，不许再赋值再赋值报 E3204

输出与输入

输出 "你好，世界"              # 打印并换行
输出 "和是：", 1 + 2            # 多值用逗号分隔，不加分隔符
写出 "下载中"                  # 打印但不换行
换行()                          # 补一个空行
输入 名字                        # 读一行，自动判型为整数/小数/文本

分支与循环

如果 分数 大于等于 90
    输出 "优秀"
否则如果 分数 大于等于 60
    输出 "及格"
否则
    输出 "不及格"
结束

重复 i 从 1 到 10            # 包含终点，走 10 次
    输出 i
结束

重复 i 从 10 到 1 步长 -1        # 步长可为负；为 0 报 E3012
    输出 i
结束

当 生命值 大于 0
    设 生命值 为 生命值 - 1
结束

遍历 水果, 序号 在 水果表 中     # 双变量：元素 + 下标
    输出 序号, "：", 水果
结束
遍历的第二个变量拿到什么？列表给下标（从 0 起）、文本给位置、字典给值。单变量遍历字典时直接得到键。

函数

函数 问候 接受 名字, 称呼 默认 "同学"
    返回 称呼 + "，" + 名字
结束

函数 求和 接受 数字...            # 可变参数，进函数就是列表
    返回 求和(数字)
结束

设 平方 为 函数(x) 返回 x * x 结束   # 匿名函数
输出 映射([1, 2, 3], 平方)          # [1, 4, 9]

容器与切片

设 数据 为 [1, 2, 3, 4, 5]
输出 数据[-2:]                  # [4, 5]，左闭右开、负索引、越界夹取
输出 取({"甲": 1}, "乙", "没有")  # 没有
输出 归约(数据, 函数(累计, 项) 返回 累计 + 项 结束, 0)  # 15

错误处理

尝试
    设 数 为 转整数("abc")
捕获 问题
    输出 错误信息(问题), " [", 错误代码(问题), "] 第 ", 错误行号(问题), " 行"
结束
抛出 "分数不能是负数"            # 生成 E4001
它不是 try 的翻译：只有语言错误会被捕获，返回 / 跳出 / 继续 / 停止 不受影响；错误对象只读，参与运算报 E3205。

06已知限制

  • 只支持 64 位 Windows 7 及以上（图形工作台与安装程序）；解释器内核本身是 C++17 可移植的。
  • 没有代码签名，SmartScreen 会提示，点「更多信息 → 仍要运行」即可。
  • 类、对象、模块、异常层级尚未启用：类 对象 导入 模块 等词已作为保留字占位，现在不能用它们当变量名。
  • 比较不能连写：1 < x < 10 报 E2005，要写成 1 < x 并且 x < 10。
  • 有硬上限：递归深度 2000 层、嵌套 200 层，超了会给出明确报错而不是崩掉。
  • 追求可读性，不追求性能：它是给第一次写代码的人用的，不是替代 C++ 的。
