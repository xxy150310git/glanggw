安装

装好之后，三步跑起来

双击安装程序，向导全中文。建议勾上「桌面快捷方式」和「.gl 文件关联」。
启动「G-Lang 编程工作台」：开始菜单 → 所有程序 → G-Lang，或双击桌面图标。
按 F11 运行。编辑器里已经放好示例代码，直接跑就有结果；F9 只查语法，Esc 停正在跑的程序。
要键盘输入的程序（两数求和、判断闰年、猜数字）先在下方的「输入」框里每行填一个值，再按 F11。
卸载：开始菜单 → G-Lang → 卸载 G-Lang，或 设置 → 应用 → 已安装的应用。卸载会删掉安装目录，自己写的 .gl 记得先复制出来。
安装包里有什么

三个程序，各管一件事

程序用途
glang-workbench.exe图形工作台，日常就用这个。写代码、F11 运行、F9 查语法、Esc 停止。左代码 / 右上输出 / 右下输入，三区可拖动分割。
glang.exe命令行解释器。在 cmd 里 glang 程序.gl，也支持 --检查、--提示、--版本。
glang-selftest.exe无界面自测程序，输出不走控制台配色，适合放进批处理里调用。
从源码构建

只要 CMake，没有别的依赖

Linux / macOS 上也可以用同一份源码编译解释器内核（图形工作台是 Win32 专用）。

tar -xzf G-Lang-v0.4.0-源码.tar.gz
cd G-Lang-v0.4.0-源码

# Windows + MinGW
cmake -S . -B build -G "MinGW Makefiles" && cmake --build build

# 其他平台（只要命令行解释器）
cmake -S . -B build && cmake --build build

# 跑回归测试：228 项
python3 tests/run_tests.py

# 产物：build/glang 与 build/glang-workbench.exe
历史版本

旧版本留档

版本号自 0.4.0 起遵循 SemVer 2.0.0。语言规范版本和发行版版本是两个号：0.3.2 是语言功能，0.4.0 只动工作台界面。

发行版语言规范主要变化
v0.4.0v0.3工作台状态栏改成六格面板。语言功能与 0.3.2 相同，旧程序一行不用改。
v0.3.2v0.3尝试 / 捕获 / 抛出；切片、安全取值、8 个高阶函数。L1 语义层收口。
v0.3.1v0.3默认参数、可变参数、匿名函数、自身；类型标注与 常量。
v0.3.0v0.3三层作用域（局部 / 全局 / 非局部）、真正的闭包、任意表达式可调用。
v0.2.2v0.24 个关键字改名（若→如果、接收→接受 等），中 改为必需，示例全部重写。
v0.2.1v0.1修崩溃与精度缺陷（整数回绕、栈溢出、负数取余），语法不变。
v0.2v0.1首次打包：工作台、安装程序、示例集。
历史包（v0.2 ~ v0.3.2 的安装程序、便携包、源码）保存在项目盘 P4工作台 目录下，按 archive-v0.3.2 这样的前缀归档。
